# Dépanini 🛠️

**A student-to-student equipment rental platform** developed as an academic team project at the Institut Supérieur des Arts Multimédia de la Manouba (ISAMM), during the 2025–2026 academic year.

## 📌 About the Project

Dépanini is a web platform designed to facilitate equipment rental between students. It allows users to explore available items, manage their accounts, and go through the rental and payment process.

## ✨ Main Features

- **User Authentication:** User registration and login.
- **Product Catalogue:** Browse available equipment.
- **Rental Management:** Manage rental-related information and item availability.
- **Shopping Cart and Payment:** Cart functionality and payment procedure.
- **Admin Dashboard:** Manage users and oversee the platform.
- **User Management:** Administrative controls, including user bans.

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL / SQL
- **Data Exchange:** JSON
